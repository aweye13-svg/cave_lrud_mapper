about=A speleological survey and subsurface modeling tool for QGIS. Processes tabular LRUD survey measurements into permanent multi-layer GeoPackages (3D conduits, 3D centerlines, 2D footprints, and labeled stations) stored in dedicated project subfolders. Features raster-to-vector extraction of georeferenced manual sketches (PDF, PNG, SVG, TIFF) using background thresholding, survey-centerline buffer masking, interior cavity flood-filling, and Douglas-Peucker simplification. Includes 7 selectable 2D passage plan styles, high-resolution 300 DPI layout and elevation profile exports with 0.25-inch margins, dynamic multi-surveyor management, dedicated plugin menu iconography on a top-level QMenu, interactive live previews, and Wavefront OBJ mesh generation.
